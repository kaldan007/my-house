# My house – 3D model

Interactive, to-scale 3D model of the house (three.js).

Live page: https://kaldan007.github.io/my-house/

- Drag to orbit, scroll to zoom, right-drag to pan.
- Mono-slope PUF roof (3′ overhang on the west), aluminium sliding windows with grills up to 8′6″, 6″ lintels, wooden doors 7′, and use the Top / Front / Back / South / North true-scale views.
- Click any door or window to see or edit its size.
